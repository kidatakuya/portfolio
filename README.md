# 🚀 フロントエンドエンジニア向け 高性能ポートフォリオ & 技術ショーケース

Next.js と React 19 の最新設計思想を取り入れた、フロントエンドエンジニアのためのモダンなポートフォリオWebサイトです。  
デザインの美しさはもちろん、「なぜその技術を選んだのか」「どのように高速化（Core Web Vitals）を達成したのか」という**技術的な詳細や設計判断**を分かりやすくアピールできる構成になっています。

初心者の方でも、**ブラウザの画面上（GUI）から直接文字や作品を打ち替えてカスタマイズ**することができます。

## ✨ 主な特徴・機能

- **技術ケーススタディ重視の作品一覧（Selected Works）**  
  単なる画面キャプチャの羅列ではなく、「採用したレンダリング戦略（Next.js PPR/Streaming）」「直面した課題と解決アプローチ」「LCP/INP/CLSの実測値」「主要コード」を各プロジェクトごとに掲載できます。
- **インタラクティブ技術実験室（Interactive Lab）**  
  採用担当者やクライアントがブラウザ上で直接触れる「10万件仮想スクロール」「Next.jsレンダリング比較マトリクス」「イベント応答テスト」を内蔵。
- **設定スタジオ（Portfolio Customize Studio）**  
  プログラミングの知識が少なくても、画面上のモーダルから作品・肩書・経歴をリアルタイムに編集・保存できます。
- **リアルタイム パフォーマンスHUD**  
  画面右下に実際のブラウザ描画速度（60 FPS）やDOMノード数を常時表示し、パフォーマンスへのこだわりを証明します。
- **Tailwind CSS v4 & アクセシビリティ準拠**  
  ゼロランタイムの最新Tailwind CSS v4を採用し、キーボード操作や高いコントラスト比を考慮した設計です。

## 🛠️ あなたの作品やプロフィールに書き換える方法（2通り）

### 方法A: ブラウザの画面上で変更する（一番かんたん）

コードを一行も書かずに、今開いているブラウザから直接変更できます。

1. 画面右上の **「作品・データ設定」** ボタンをクリックします。
2. 設定ウィンドウ（スタジオ）が開きます：
   - **基本プロフィール タブ**: お名前、肩書、自己紹介文、連絡先メールアドレス、活動拠点などを入力します。
   - **作品・プロジェクト タブ**: 既存の作品の「鉛筆アイコン（編集）」を押してタイトルや課題・解決策を書き換えたり、「新規作品を追加」ボタンで新しい作品を増やせます。
3. 画面右下の **「変更を保存して反映」** をクリックします。
   - これだけで、即座にポートフォリオの画面全体があなた自身の情報に切り替わります！
   - ※ブラウザの保存領域（LocalStorage）に記録されるため、再読み込みしても消えません。
4. **コードとして保存したい場合**:
   - 設定ウィンドウの「**データ書き出し / Export**」タブを開きます。
   - 「**portfolioData.ts をダウンロード**」を押して保存し、プロジェクトの `src/data/portfolioData.ts` と置き換えるだけで、永続的な初期データとして反映されます。

## 💻 パソコン（ローカル環境）での動かし方

初めての方でも以下の3ステップで自分のパソコン上で動かせます。

### 準備するもの
- パソコンに **Node.js**（バージョン18以上、推奨20以上）がインストールされていること。  
  ※まだの方は [Node.js公式サイト](https://nodejs.org/) から「LTS（推奨版）」をダウンロードしてインストールしてください。

### 手順

1. **ターミナル（端末）を開く**  
   VS Codeを使っている場合は、上部メニューの「ターミナル」→「新しいターミナル」を開きます。

2. **必要なパッケージをインストールする**
   ```bash
   npm install
   ```
   （必要なライブラリが自動でダウンロードされます。数十秒ほど待ちます）

3. **開発用サーバーを起動する**
   ```bash
   npm run dev
   ```
   実行すると、以下のようなメッセージが表示されます：
   ```text
   VITE v8.x.x  ready in 200 ms
   ➜  Local:   http://localhost:3000/
   ```

4. **ブラウザで確認する**  
   Google Chromeなどのブラウザを開き、アドレスバーに `http://localhost:3000` と入力して開きます。ポートフォリオが表示されれば成功です！

## 🌐 Web上に公開する（デプロイ）方法

ポートフォリオが完成したら、世界中の人に見てもらえるようインターネット上に公開しましょう。

### おすすめ公開先: Vercel（一番おすすめ・無料枠あり）
1. [GitHub](https://github.com/) にこのプロジェクトをアップロード（Push）します。
2. [Vercel](https://vercel.com/) にGitHubアカウントでログインします。
3. 「Add New...」→「Project」を選び、先ほどのGitHubリポジトリを選択します。
4. 「Deploy」ボタンを押すだけで、約1分であなた専用のURL（例: `https://your-portfolio.vercel.app`）が発行されます。

### 本番用ファイルのビルド
自分のサーバーや他の静的ホスティング（Cloudflare Pages、GitHub Pages、AWS S3など）にアップロードしたい場合は、以下のコマンドを実行します：
```bash
npm run build
```
実行すると `dist/` というフォルダの中に、最適化・圧縮されたWebファイル一式が生成されます。

## ❓ よくある質問・困ったときは

#### Q. 画像を自分のスクリーンショットや写真に変えたい
1. 使いたい画像（PNGやJPG）を `src/assets/images/` フォルダの中に入れます（例: `my_project.png`）。
2. `src/data/portfolioData.ts` の上部で画像を読み込みます：
   ```typescript
   import myProjectImg from '../assets/images/my_project.png';
   ```
3. プロジェクトの `thumbnail: myProjectImg` と指定すれば差し替え完了です。

#### Q. 設定を変更したら画面が崩れたり動かなくなった
- 画面右上の「作品・データ設定」を開き、左下の「**初期状態に戻す (Reset)**」を押すと、いつでも安全に初期デモ状態へ復帰できます。

#### Q. Next.js の本番プロジェクト（App Router）へ移行したい
- コンポーネントはすべてモダンなReact/TypeScript標準で構築されており、Tailwind CSS v4に対応しています。
- 各コンポーネントコード（`src/components/*`）とデータ（`src/data/*`）をそのまま Next.js 14/15 の `app/` 配下へ持っていくことが可能です。
